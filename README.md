Auxio

Auxio — простой, быстрый и современный аудиоплеер для Android, предназначенный для воспроизведения локальной музыки.

«🎵 Музыка на вашем устройстве — без лишнего.»

✨ Возможности

- 🎧 Воспроизведение локальных аудиофайлов
- 📚 Удобная медиатека
- 🔎 Быстрый поиск треков, исполнителей и альбомов
- 💿 Обложки альбомов и метаданные
- 📂 Навигация по исполнителям, альбомам и трекам
- ▶️ Фоновое воспроизведение
- 🔒 Управление с экрана блокировки
- 🎛️ Управление через Bluetooth-устройства
- 🚗 Поддержка системных элементов управления мультимедиа
- 📋 Плейлисты
- ⚡ Быстрый и минималистичный интерфейс
- 🌙 Поддержка тёмной темы
- 📱 Оптимизация для современных версий Android

🎯 Философия

Auxio создан с простой целью: позволить слушать собственную музыку без лишних функций и сложностей.

Плеер не должен мешать музыке. Поэтому интерфейс Auxio остаётся минималистичным, а основные действия доступны за несколько нажатий.

📱 Требования

- Android
- Локальные аудиофайлы на устройстве
- Разрешение на доступ к музыкальной медиатеке, если оно требуется вашей версией Android

Минимальная поддерживаемая версия Android зависит от конкретного релиза Auxio.

🚀 Установка

Установите Auxio из доступного источника распространения проекта.

После установки:

1. Запустите Auxio.
2. Предоставьте необходимые разрешения.
3. Дождитесь сканирования медиатеки.
4. Выберите трек и начните воспроизведение.

🎵 Музыкальная библиотека

Auxio использует локальную медиатеку устройства.

Если музыка не отображается:

1. Убедитесь, что файлы находятся на устройстве.
2. Проверьте формат аудиофайлов.
3. Проверьте разрешения Auxio.
4. Обновите или пересканируйте медиатеку.
5. Перезапустите приложение, если изменения не появились.

🎧 Фоновое воспроизведение

Auxio поддерживает воспроизведение музыки при свернутом приложении и выключенном экране.

Если воспроизведение неожиданно останавливается, причиной может быть ограничение фоновой активности со стороны Android или производителя устройства.

Проверьте настройки:

Настройки → Приложения → Auxio → Батарея

и разрешите приложению работать в фоне, если такая опция доступна.

📂 Поддерживаемые файлы

Поддержка аудиоформатов зависит от возможностей Android и используемых системных компонентов.

Распространённые форматы, такие как MP3, FLAC, OGG и другие, могут поддерживаться при наличии соответствующего системного декодера.

💿 Метаданные

Auxio может использовать метаданные аудиофайлов для отображения:

- названия трека;
- исполнителя;
- альбома;
- номера трека;
- обложки;
- другой доступной информации.

Если данные отображаются неправильно, проверьте метаданные самого аудиофайла.

🔐 Конфиденциальность

Auxio предназначен прежде всего для работы с музыкой, хранящейся локально на устройстве.

Приложение не требует создания аккаунта для базового использования плеера.

Перед использованием конкретной версии приложения ознакомьтесь с её политикой конфиденциальности и документацией проекта.

🛠️ Разработка

Клонируйте репозиторий:

git clone <repository-url>
cd auxio

Затем откройте проект в Android Studio и дождитесь синхронизации Gradle.

Для сборки проекта используйте стандартные Gradle-задачи:

./gradlew assembleDebug

Для запуска тестов:

./gradlew test

Конкретные команды и требования к окружению могут отличаться в зависимости от текущей версии проекта.
